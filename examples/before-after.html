Drag Limits & Rubber Band

Rule 14Rule 19

After (Rubber band)
/* Before: hard stop at 120px */ if (x > 120) x = 120; /* After: Apple-style logarithmic rubber band formula */ const rubberBand = (x, dim) => (1 - 1 / ((x * 0.55) / dim + 1)) * dim; if (x > 120) x = 120 + rubberBand(x - 120, 54);
